What is Prestige?

When your agent reaches Level 20, you can choose to Prestige. This resets your agent back to Level 1 with base stats, but grants a permanent Prestige Bonus that applies to all future progression.

  • ⭐ Prestige 1: +5% XP gain, +2% base stats
  • ⭐⭐ Prestige 2: +10% XP gain, +5% base stats
  • ⭐⭐⭐ Prestige 3: +15% XP gain, +8% base stats
  • ⭐⭐⭐⭐ Prestige 4: +20% XP gain, +12% base stats
  • ⭐⭐⭐⭐⭐ Prestige 5: +25% XP gain, +15% base stats, exclusive skin
