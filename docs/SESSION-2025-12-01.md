## What We Discussed

### 1. LRN Architecture Overview
Explored the existing Primordial codebase:
- **Living Resonance Network (LRN)**: Fourier-based neural architecture (~218K params)
- **Continuous learning**: Online single-sample updates with reward modulation
- **Multi-modal**: Vision (32 rays), audio (stereo), proprioception (7), touch (8)

### 5. Research Paper Discussion
How to prove LRN is trainable:
- Measurable baselines vs trained performance
- Compare Fourier mixing vs Transformer attention

- Potential venues: NeurIPS, ICML, ICLR, CoRL

### 6. Speech Learning Idea (New Direction!)
User proposed: "Could we teach it to speak? It has ears, give it phoneme control."

This is potentially more novel than Minecraft:
- Infants learn speech through babbling + imitation
- No LLM, no text - pure sensorimotor learning
- Audio in → Fourier mixing → phonemes out → TTS → hear self → learn

Components needed:
- MelSpectrogramEncoder (replace simple AudioEncoder)
- SpeechHead (44 phonemes + duration + pitch)
- Piper/Sherpa-ONNX integration for TTS
- Audio similarity loss function

Training curriculum:
1. Phoneme imitation (classification)
2. Phoneme production (synthesis)
3. Phoneme sequences (babbling)
4. Word imitation (emergent behavior)

## Training Results (100 Epochs)

```
Epochs 1-10:   2% → 48% accuracy (rapid learning)
Epochs 10-40:  48% → 62% accuracy (slower improvement)
Epochs 40-100: 62% → 63% accuracy (plateau)

Best: 63.3% on 41 phonemes (random baseline = 2.4%)
Final loss: 0.69 (started at 3.7)
```

**Interpretation:** The Fourier-based architecture learns phoneme classification from mel spectrograms, but hits a ceiling around 63% with the simple linear encoder. Next steps:
- Try CNN encoder for richer features
- Use real Piper TTS instead of DummyTTS tones
- Larger model / more training data
